Privacy Policy

Tab Groups Dashboard runs entirely inside your browser. Your data never leaves your device.

Last updated: May 5, 2026

1. Overview

Tab Groups Dashboard is a Chrome extension that organizes your open tabs by Chrome tab groups and windows. It is designed to work entirely within your browser with zero external communication.

We do not require an account, sell data, use remote code, or transmit your browsing information to any external server.

2. Data We Access

DataPurpose
Open tab metadata (title, URL, favicon)Display tabs organized by group
Chrome tab group info (name, color)Show group labels and colors
Window informationOrganize tabs by window
User-created favoritesDisplay pinned favorite sites

3. Permissions Explained

PermissionPurpose
tabsRead open tabs to display them on the dashboard
tabGroupsRead Chrome native tab group names, colors, and state
storagePersist favorites and preferences locally
activeTabNavigate to a tab when you click on it

4. Data Storage

All data is stored locally via Chrome's chrome.storage.local API. Data persists until you:

  • Remove it manually within the extension
  • Clear extension data via Chrome settings
  • Uninstall the extension

No data is ever transmitted externally.

5. Data Sharing

We do not collect, transmit, sell, or share any user data with third parties. Period.

7. User Controls

You can:

  • Remove any favorite at any time
  • Clear all extension data via Chrome's extension management
  • Uninstall the extension to remove all stored data
  • Use Chrome's "Clear browsing data" to wipe extension storage

8. Changes to This Policy

If this policy is updated, the "Last updated" date will reflect the change. Significant changes will be noted in the extension's changelog.

9. Contact

For questions about this privacy policy, please open an issue on our GitHub repository.
