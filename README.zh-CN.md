# Tab Groups Dashboard

> 一个 Chrome 新标签页扩展，按 **Chrome 原生标签页分组** 和窗口来组织你的所有打开标签页，支持常用标签快捷访问和一键窗口跳转。

## 功能特性

### 核心功能

- **按分组显示标签页** — 以 Chrome 原生 Tab Groups 的颜色和名称来组织标签页
- **窗口卡片** — 每个浏览器窗口显示为一个可折叠卡片（默认折叠），header 中直接显示该窗口内的分组名称标签
- **一键跳转窗口** — 通过 `↗` 按钮直接切换到目标窗口，无需展开卡片
- **快速标签导航** — 点击任意标签页即可切换到对应窗口并激活该标签

### 常用标签

- **收藏常用标签** — Google 风格的快捷方式网格（图标 + 短名称）
- **智能名称识别** — 未填写标题时自动从 URL 提取友好名称（如 `mail.google.com` → "Gmail"）
- **拖拽排序** — 拖动收藏项重新排列顺序，新位置自动保存
- **键盘快捷操作** — 在添加弹窗中按 `Enter` 直接确认添加

### 界面与搜索

- **全局搜索** — 按标题或 URL 实时过滤标签页（`Ctrl/Cmd + K`）
- **折叠/展开** — 切换分组和窗口的显示状态，状态跨会话持久保存
- **深色/浅色主题** — 一键切换，偏好本地保存
- **徽章计数** — 扩展图标显示标签页总数，颜色编码（绿 → 黄 → 红）

### 隐私

- **100% 本地运行** — 无服务器、无账号、无追踪。所有数据保存在 `chrome.storage.local`

## 安装方法

### 从源码安装（开发者模式）

1. 克隆本仓库：
   ```bash
   git clone https://github.com/your-username/tab-groups-dashboard.git
   ```

2. 打开 Chrome 浏览器，访问 `chrome://extensions/`

3. 开启右上角的 **开发者模式**

4. 点击 **加载已解压的扩展程序**

5. 选择仓库中的 `extension/` 文件夹

6. 打开新标签页即可看到 Tab Groups Dashboard！

## 权限说明

| 权限 | 用途 |
|------|------|
| `tabs` | 读取所有打开的标签页信息以便在面板中显示 |
| `tabGroups` | 读取 Chrome 原生标签页分组的名称、颜色和状态 |
| `storage` | 本地保存常用标签、折叠状态和主题偏好 |
| `activeTab` | 点击标签页或窗口时执行跳转 |

## 工作原理

1. **数据获取** — 调用 `chrome.windows.getAll()` 和 `chrome.tabGroups.query()` 构建三级层次结构：窗口 → 分组 → 标签页
2. **渲染** — 渲染可折叠的窗口卡片，header 中显示分组颜色标签；窗口默认折叠
3. **窗口跳转** — `↗` 按钮调用 `chrome.windows.update(windowId, { focused: true })` 直接切换窗口
4. **标签导航** — 点击标签页调用 `chrome.windows.update()` + `chrome.tabs.update()` 切换窗口并激活标签
5. **常用标签** — 存储在 `chrome.storage.local`，支持拖拽排序，从 URL 自动识别站点名称
6. **自动刷新** — 监听标签页/分组/窗口变化事件，实时更新界面

## 技术栈

- **原生 JavaScript** — 无框架依赖，无构建步骤
- **CSS 自定义属性** — 主题系统、响应式设计、拖拽视觉反馈
- **Chrome Extension Manifest V3** — 现代扩展架构
- **Chrome APIs** — `tabs`、`tabGroups`、`windows`、`storage`
- **Pillow（仅构建时）** — 多尺寸图标生成
